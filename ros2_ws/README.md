# RUDRA ROS2 Workspace

This is the ROS2 Jazzy migration workspace for the RUDRA robot.

Main development machine:
- rudra NUC on the robot

Control and visualization machine:
- aghora laptop

Workspace layout:
- src/ contains ROS2 packages.
- build/ is generated by colcon.
- install/ is generated by colcon.
- log/ is generated by colcon.

Do not commit build/, install/, or log/ to Git.
